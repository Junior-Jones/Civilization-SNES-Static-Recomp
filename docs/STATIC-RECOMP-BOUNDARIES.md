# Civilization 1.1.1 static-console boundaries

Civilization 1.1.1 is one static SNES console specialized to the exact Civilization
USA ROM. The boundary is not a screenshot, frame number or menu. Generated
S-CPU authority is the complete current offline fixed point: 103,584 exact
PBR:PC:E:M:X contexts, 69 finite indirect sites, zero analysis frontiers and an
empty work queue.

Reset/setup ownership retains the source-proved one-way settling cut at
C0:8155. This is lifecycle classification inside the one static console, not a
second runtime or a frame-zero cutoff.

Finite indexed-indirect proof records semantic selector offset, raw CPU X,
effective pointer address and exact ROM target. C2:37A7 and C3:236E are the only
proved sites where raw X is pre-biased to the table address. The current proof
independently structurally re-decodes all 69 finite sites, recertifies the 17
formerly older-method receipts, and records complete producer/value sets rather
than treating table adjacency as authority.
Unknown raw-X values remain fail closed.

The handwritten machine layer remains target-bounded. Visible BGMODE operation
is Mode 1 or Mode 3, VMAIN is source-proved at $80, manual DMA/HDMA remain in
proved Civilization domains, and PPU reads are limited to the source-proved
multiplication ports $2134-$2136. M7A/M7B use does not authorize a general Mode
7 renderer.

Full Static S-SMP/S-DSP remains the only audio authority. MesenCE is an
independent comparison oracle/reference only and is never runtime or generation
authority.

Host persistence is outside guest CPU authority. Battery SRAM survives a console
reset as real cartridge-backed state. Persistent snapshot slots capture the
already-static paused machine plus Full Static audio; loading a snapshot cannot
add a CPU edge, decode an opcode or widen an MMIO domain.

Natural gameplay is validation only. It may locate a new fail-closed frontier,
but it never authorizes an edge or hardware mode in the frozen version.
