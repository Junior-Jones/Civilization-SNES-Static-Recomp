# Civilization Version 36 milestone list

## M1 - Short accessible test protocol

- Define a short action batch format so one test step does not wait on repeated
  frame-by-frame interaction.
- Announce each checkpoint and failure in native status text for a screen reader.
- Capture a screenshot only at decision points or unexpected states.

## M2 - User-guided release validation

- Validate startup, new-game menus, map input, city view, saves and snapshots.
- Validate keyboard and gamepad control profiles plus Full Static audio output.
- Record the first reproducible fail-closed frontier without widening at runtime.

## M3 - Proof work only if evidence requires it

- For a reproducible frontier, prove producers, effective addresses, targets and
  hardware reads offline before changing the closed authority.
- Keep all existing barriers unless a complete replacement proof supersedes one.

## M4 - Distribution gate

- Repeat clean MSVC and GCC builds and the maintained machine tests.
- Validate a clean extracted app archive on a second Windows machine.
- Freeze a Version 36 archive only after the shorter natural route completes.
